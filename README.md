# Valentine Platform
This is the new Next.js + Supabase platform.

## Storybook storefront

The Batman marketing demo uses the audited public project configured in `lib/storefront-demo-config.ts`. Set `NEXT_PUBLIC_STORYBOOK_SPIDERMAN_DEMO_URL` to the separately provisioned Spider-Man marketing project before the final storefront build. Until that value exists, the demo modal exposes Batman only and never labels Batman data as Spider-Man.

Product screenshots live in `public/assets/storybook-features/` and are WebP captures from the real Storybook renderer. Do not replace them with generated mockups.
